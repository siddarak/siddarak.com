## 🚀 Build & Deployment Flow
- **Verification:** Always run `npm run build` locally to verify TypeScript and lint compilation before staging changes.
- **Deployment:** The website is automatically deployed via Vercel git integration. Pushing commits to the `main` branch of the remote repository (`origin`) triggers a live build.
