# Campaign look (UI agent owns this file)

This chat does **not** write website copy. Read `CAMPAIGN-COPY.md` and put those strings on the page. Photos are placeholders until the hub chat says otherwise.

Personal site (`/`, `/about`, `/projects`) stays as it is. Campaign work lives under `/campaign` and `/campaign/studio`.

## Job

A **poster that scrolls** — yard-sign energy, concert-poster type, Pine + Punch. Not Ayomide’s memo. Not Cornell carnellian. Not a clone of Robbie’s navy/orange **or** his Share/WhatsApp button row.

Information architecture (steal from Robbie, not his chrome): **vision → why → platform → about → vote.** One scroll. Sticky: name + vote dates only. Email in the footer, not a hero CTA stack.

Artistic / funky **while still looking like a real candidacy**. One distinctive move (marquee, stacked color bands) is enough. Not a rave, not agency canvas theatrics.

## Layout

Sticky bar → hero (type + framed photo, **no button row**) → optional short message band → why → platform as **full-bleed bands** (not three equal white cards) → about → punch closer → footer. Do not require or repeat a slogan.

Mobile: stack hero; keep type huge; bands stack.

Do **not** add 100-day plans, forms, or extra routes except `/campaign/studio`.

## Color (decision for studio)

Campaign sites that stand out drop red/blue on purpose (Obama Hope’s off-patriotic set; AOC purple/yellow; Victorian Greens use **green plus pink** on collateral). We want that move: **recognizable as a candidate, not as Cornell, not as Robbie.**

Robbie’s *system* (steal): dark field + hot accent + white paper + condensed display type.  
Robbie’s *hues* (don’t steal): `#004AAD` / `#FF751F`.  
Cornell (don’t use): carnellian / maroon.

**Locked (Sid, 2026-08-28): Pine + Punch.** Night Punch and Kelly + Pink stay in the studio as rejects, not as live options for `/campaign`.

This is pink and green in **poster weights**: forest, not mint; magenta, not blush.

Alts in `/campaign/studio`: **Night Punch** (near-black + magenta, less green) and **Kelly Pink** (brighter green, still formal). Pick there; write the winner into this table.

Contrast: body text ≥4.5:1 on paper and on pine.

## Type

- Display: condensed sans, all-caps name (Anton or equivalent — poster).
- Body: grotesque/humanist (Archivo, something similar). **Not** the personal site’s Geist Mono on the campaign page.
- Optional script “for” (Caveat-style) only if it still feels like a poster.
